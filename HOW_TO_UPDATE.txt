HƯỚNG DẪN CẬP NHẬT VÀ TRIỂN KHAI
==================================

Cấu trúc file (dạng phẳng, không dùng thư mục con)
-----------------------------------------------------
index.html                  Trang chọn chương trình
ausbildung.html              Dashboard Ausbildung (98 vị trí)
18b-19c-16d.html             Dashboard §18b, 19c, 16d
admin.html                   Trang quản lý đối tác, chỉ admin vào được
alma-logo.png                Logo dùng cho phần đầu trang
alma-logo-white.png          Logo dùng cho phần chân trang
auth-gate.js                 Lớp đăng nhập dùng chung (bản Supabase)
config.js                    Chứa địa chỉ và anon key của dự án Supabase
generate_dashboards.py       Script cập nhật dữ liệu cho cả hai dashboard

Lưu ý: dùng file phẳng (ausbildung.html) thay vì thư mục con
(ausbildung/index.html) vì giao diện tải file trên GitHub không nhận đúng
khi kéo cả thư mục có nhiều file cùng tên index.html. Khi tải file lên
GitHub, kéo từng file một, không kéo cả thư mục.

Đăng nhập hiện dùng Supabase, không còn dùng Netlify Identity nữa. Xem chi
tiết cách thiết lập trong SUPABASE_USER_MANAGEMENT.md. Nếu Identity của
Netlify đã từng được bật, tắt đi cũng được vì không còn dùng đến.

Mỗi dashboard tự chứa toàn bộ dữ liệu vị trí ngay trong file index.html,
không cần file CSV rời.

Lưu ý: dashboard §18b, 19c, 16d hiện dùng cấu trúc cột tiếng Việt riêng
(Năm, Ngày đăng, ID, Tinh trạng, Ngành, Vị trí, Brochure, Loại hình doanh
nghiệp, Thành phố, Bang, Chủ Doanh nghiệp Việt/Đức, Yêu cầu chính,
Additional notes, Trình độ tiếng Đức, Thời gian bắt đầu, Lương cứng trước
thuế, Lương cứng sau thuế, Phúc lợi Thưởng & Ghi chú, Nhà ở, Giá thuê nhà,
Thời gian làm việc, Ngày nghỉ, Số ngày nghỉ phép, Chi phí sinh hoạt hằng
tháng), khác với dashboard Ausbildung vẫn dùng cấu trúc cột cũ. Script đã
được cập nhật để đọc đúng cả hai cấu trúc cùng lúc từ cùng một file Excel.

Cột Brochure có thể là link chèn trực tiếp, công thức HYPERLINK, hoặc dán
thẳng đường dẫn Google Drive, script đều đọc được cả ba kiểu.

Bước cập nhật dữ liệu
----------------------
1. Trong Google Sheet, chọn File, sau đó Download, chọn định dạng
   Microsoft Excel (.xlsx). Tải về toàn bộ workbook (không phải từng sheet
   riêng lẻ).
2. Mở terminal tại thư mục chứa các file trên, chạy lệnh sau, thay đường
   dẫn file cho đúng với file vừa tải về:

   python3 generate_dashboards.py --xlsx "duong_dan_file.xlsx"

3. Script sẽ báo số vị trí đã cập nhật cho từng dashboard.
4. Hai file ausbildung.html và 18b-19c-16d.html đã được ghi đè với dữ liệu
   mới. Không cần chỉnh sửa gì thêm.

Bước triển khai lên GitHub
-----------------------------
1. Vào kho GitHub đang dùng, bấm Add file, chọn Upload files.
2. Kéo từng file một vào (không kéo cả thư mục), xác nhận ghi đè các file
   trùng tên, bấm Commit changes.
3. Netlify sẽ tự động phát hiện commit mới và triển khai lại, không cần
   thao tác gì thêm trên Netlify.
